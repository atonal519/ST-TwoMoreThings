# 两三事 0.5.2

## 普通 HTTP 与浏览器兼容

- 修复使用普通 HTTP 地址访问酒馆，或浏览器不提供 `crypto.randomUUID` 时，新增 API、另存连接报错而无法保存的问题。
- 消息、联系人、群聊、默认头像、收藏、拍一拍和图片命名统一采用兼容的编号生成方式。已有编号和聊天内容保留，API 共享连接与选择方式沿用原规则。
- 新导出的随卡启动脚本也支持上述环境，可正常生成脚本与加载节点的编号。

## 已有随卡脚本

- 更新核心不会自动改写已经导入的脚本内容。如果旧启动稿在手机出现前就报 `randomUUID` 错误，请保留原脚本的数据，换用新版导出的启动代码。
