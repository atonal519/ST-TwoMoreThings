# 两三事 0.7.2

- 新增相机完整照片预设，可在同一弹窗管理多组人物和多条提示词。支持零人、单人或多人，选择原词直出或人设润色，生成结果统一归入相册。相机位于第一屏右下，收藏夹移至第二屏原相机位置。
- 相册任意照片可设为照片墙，支持拖动、缩放和方向键微调，最小缩放展示完整原图。已有墙图可重新调整，确认后保存取景。
- 人设润色将共同场景与每个人的动作分别交给柏宝绘，并给对应角色附原人物库外貌；多人按实际选中槽位对应，保留模板的构图、分格和权重。
- 修复正文短信把手机持有者误建为联系人、收发方向反转的问题，新导入按明确的本人身份与同楼双向关系归入会话。
- 正文私聊中的微信转账金额可识别为转账卡片。当前楼可收下或退回并查看状态，历史消息保留卡片展示。
- 手机首次可见时检查当前角色卡的楼内短信注入词，检测到注入词与当前版本不同时会显示提醒，可点“去更新”进入内容设置，再由用户点击“更新”。
- 改进粤语文字与模拟语音的同次译文要求，并兼容紧邻原文返回的独立译文字段，让对应译文正确保存和显示。
