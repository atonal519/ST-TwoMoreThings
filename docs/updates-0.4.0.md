# 两三事 0.4.0

- 新增“两事”微博，广场手动刷新约15条内容，以约95%的独立公共生活为主，分散领域、人群和地方，并穿插少量推广。
- 两事热榜独立生成约15个话题和摘要，点开详情后手动加载约8条相关微博，重进直接阅读，并在同次生成内判断人物公众身份和事件传播条件。
- 两事关注页按user设定、兴趣和已保存公开内容独立刷新约15条微博，模拟可能已关注的账号，关注状态仅作展示。
- 两事支持手写或AI帮写预览，正文与配图描述可任选其一，自己发布后可从卡片右下角菜单编辑或删除，配图点击后才生成。
- 两事“我的”显示当前个人资料头像、网名和模拟统计，下接本人微博列表，发博及已有本人帖统一使用个人资料网名。
- 两事引用可读原博，详情分转发和评论阅读并按需追加互动，本地点赞会亮红心和轻微缩放，再点取消。
- 本人微博按当前账号与正文默认生成少量自然评论，转发可为0，仅资料明确当前号无人关注时可全空。
- 两事详情单行显示转发、评论和赞的总数，白鳥系列推广采用高互动统计。
- 手机内已保存公开内容和折叠历史按知情范围流转，当前短信段只供本会话，群消息保留当时成员范围，公开批量生成不带私聊。
- 联系人可手工关联同人账号并共享近期已折叠记忆，主性格和人物记忆共用，账号表达与头像独立，所属关系保密且本人账号不由AI代发。
- 主内容生成统一参考清洗后的最新AI一楼，公开内容仅采用明确已公开事实，两事广场仍以世界生活为主，加载更多继续围绕所选帖子。
- 动态刷新、个人历史补充和线上方式重提炼不参考上一稿，人物资料、短信、剧情与记忆仍沿各自来源约束。
- 手机生成只取近期有界记录，正常保存清理退役待办字段，挂图失败清理本次无引用图片。
- 移除待办提取、确认卡片和应用入口，短信与群聊照常衔接，日历保留。
- 在“设置 → 内容设置 → 楼内信息注入”点“注入”，可让主楼显示短信气泡并自动存入手机继续聊。
- 文本连接支持保存、命名另存和确认删除，列表直接显示配置名，地址与密钥共享，切换配置带入默认模型，另选模型单独保存在两三事。
- 手机统一撤销自行设置的模型输出token上限，输入仍按近期预算裁切，输出与思考交所选模型和接口。
- 完整模型答复中的引号、逗号等格式错误支持本地兼容读取，继续按原内容与身份规则保存，不增加模型请求。
- 手机复用共享破限词设置，非空自定义保留原文，留空使用内置默认。
- 短信、群聊、论坛和动态支持默认语言，联系人单独设置优先，粤语及其他非标准汉语内容在同次生成中附标准汉语译文。
- 原文与译文重复时合并显示。
- 联系人头像支持上传、移除和恢复，列表与资料页统一显示千千结优先、固定Cameo补充的头像。
- 操作提示统一为紧凑浮层，成功2.5秒、错误5秒后自动消失，均可手动关闭。
- 经典锁屏图案铺至屏幕底部，当前图案与动态时钟准备好后整体呈现。
- 手机标题、时钟和操作标签不再拖选，输入与消息正文仍可复制，桌面图标统一使用主题强调色、底色按列交错。
- 群聊引用和输入草稿采用清晰的主题底色与文字，各页统一使用圆角细滚动条，并去掉板块介绍性副标题。
- 同楼剧情时间明确相差超过一小时时，手机优先采用千千结或柏宝书时间。
- 设置页底部固定显示实际版本与公告入口，图片卡生成时显示居中的进度提示。
- 插件和随卡版共用单文件核心，减少启动时逐个加载源码模块的请求，随卡更新继续保留联系人、配置和聊天记录。
- 随卡更新改用CDN的最新semver版本清单并按完整SHA加载核心，发布时创建版本标签、刷新别名缓存并回读确认版本。
