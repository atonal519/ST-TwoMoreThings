# 两三事 0.4.3

- 异步更新时保留正在编辑的输入、光标选区与中文输入连续性，减少未发送草稿被打断。
- 短屏键盘下跟随当前编辑区，看图返回和后台完成通知保留原阅读与输入位置。
- 短信、微博、通讯录、头像和单条消息操作统一为按钮旁的小菜单，设置字段使用内部下拉。
- 同类小操作统一按下和键盘焦点圆角，表单主次操作与危险删除按钮更清楚。
- 联系人及群聊删除使用手机内确认，连接设置首次默认折叠。
- 论坛顶部按跨帖复用的宽分类筛选，主帖生成提示加强背景、分段展开与独立取材。
- 识别主楼短信时跳过草稿和审核片段，减少同一条短信重复出现。
- 微博和动态的发布时间改为清楚的日期与时分。
