# 两三事 0.6.1

- 论坛页标题直接显示当前“圈内”或“圈外”，点标题可切换范围。
- 正文手机参考超过3000字符时，沿原一次请求生成目标100字的摘要。返回的有效摘要即使超过100字，也会完整带入参考，修复已有摘要却提示准备失败的问题。
- API按实际选用模型识别GPT-5、GPT-6、o1、o3、o4系列，省略程序默认temperature，兼容这些系列对参数的要求。
- 电脑端有提交动作的文字输入统一支持 Enter 发送、发布或保存，多行框用 Shift+Enter 换行。中文选词回车用于确认文字，长按回车只提交一次。手机多行框用 Enter 换行，API副本名称回车保存副本。
