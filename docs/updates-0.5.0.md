# 两三事 0.5.0

## 相册与备注

- 新增相册，汇总短信、群聊和帖子图片；同图合并展示多处来源；已生图与原画面描述随当前聊天保留，刷新内容、重生成或删除来源后仍可查看。
- 新增圆孔与燕子打孔拼贴：逐个拖动取样孔位、调整大小，可下载完整作品或透明碎片 PNG。
- 联系人资料新增「TA 给我的备注」，在正常私聊回复中顺带生成或更新。

## 通知与外观

- 手机上沿新增通知下拉面板与日夜快切，通知历史随当前聊天保存；点开通知后移除这一条；「清除通知」清空历史与当前提醒，保留消息和帖子。
- 通知面板空白处可点击收起，锁屏展开时完整遮住底层页面；清除按钮改为半透明样式。
- 外观设置支持字体 CSS 链接，默认使用有爱圆体；韩文原文采用 Gaegu，日文原文采用 Yomogi；统一双语内容的字号、间距与评论姓名排版，突出汉语译文。
- 主楼短信气泡随手机日夜切换配色；锁屏指纹按下时去掉方形底色。

## 聊天与动态

- 调整回复提示：私聊每轮至少 3 条，群聊每轮合计至少 6 条，按需要安排成员发言。
- 统一人物知情规则，按亲历、明确告知、转告与已公开内容取材；ainstgram 动态结合账号的公开身份与对外形象选择内容，并移除生成动态、评论时附带的短信。
- 补齐评论、回应、转发等副内容的逐条译文提示。
- 楼内短信兼容「老板-张三」「张三（老板）」等带分隔的姓名写法；修正未闭合短信标记跨入后续正式短信的问题，保留草稿过滤。

## 连接与日历

- 连接预设可编辑、另存、重命名和删除；新增 API 使用独立表单，搜索与副本名称输入支持各自的 Enter 操作。
- 日历支持节日、生日、纪念日和自定日程；没有可靠剧情日期时显示本地日期；短信与群聊可参考构画的相关刻度日程，这项联动需要构画提供新版日程读取接口。

## 更新提示

- 以前已注入楼内短信格式的用户，更新并刷新后，请到「设置 → 内容设置 → 楼内信息注入 → 更新」替换已保存的旧显示规则。
- 译文与生成提示调整从后续生成生效，已有内容继续保留。
