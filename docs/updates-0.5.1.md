# 两三事 0.5.1

## 拍一拍与收藏

- 双击私聊或群聊消息里的头像，可以拍对方或自己，留下居中小记录。当前段末尾仍是本人拍同一目标的记录时，再双击该头像即可撤回；角色可在下次正常回复里自然回拍。
- 新增收藏夹，可保存私聊、群聊、拍一拍与富消息，以及两事、ainstgram、论坛的主帖和两事独立转发。保留当时的完整正文、译文、作者、时间和已有配图，按应用筛选阅读；评论和回复没有单独收藏入口。
- 收藏按钮固定显示「收藏」，空心书签表示未收藏，实心表示已收藏；在来源处再点一次即可取消。收藏详情顶部右侧也可确认取消，只移除这份副本，保留来源内容。
- 收藏副本独立保存，清屏、刷新、改文或删除来源后仍可阅读。已有图片沿用收藏时的资源，不重新生成；收藏不会进入模型或随卡包。

## 完整材料与正文参考

- 移除手机自行添加的输入条数、字数和检索查询长度裁切，符合当前任务与知情范围的短信、历史、卡文、世界书、已注入摘要及评论转发等材料完整提供，长聊可承接当前段开头。
- 内容设置新增「参考正文楼」，默认 1，填 0 关闭正文参考，可填任意非负整数。AI 与用户主楼记录共同计入最近 N 楼，按原顺序完整提供；用户输入保留原文，AI 正文沿用原清洗与短信去重。时钟与短信批次仍取最新 AI 楼。
- 短信带入主楼时，原有超过 3000 字符后的一次简短摘要继续保留，摘要输入也使用完整的合格当前段短信。

## 操作与布局

- 清屏改用手机内确认弹窗；调整小按钮、确认框、底栏与输入栏的间距，增加输入空间，统一收藏详情的顶部操作。
