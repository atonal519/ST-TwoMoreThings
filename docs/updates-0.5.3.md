# 两三事 0.5.3

- **会话列表日期**：短信列表中，联系人和群名右侧显示末条消息已记录的日期与时间，方便辨认各会话的消息时间。
- **同楼短信追加**：重新生成同一楼，新候选的短信会继续加入手机，旧候选由你自行删除。同一份结果反复打开不会重复导入，手删后也不会因重开或切回该候选而补回。
- **已入群目录**：开启「短信带入正文」后，正文会收到当前已加入群的群名和成员，名单随当前聊天更新，没有新短信时也能参考。
- **微信互动**：放松私聊和群聊的提示，引导人物结合人设和已有对话自然展开，允许停顿或收尾，不要求每轮邀约或追问。
- **短信照片提示**：「点击生成」移到图片占位区内；已有图片直接点图查看。
- **短信空白行**：清理正文短信标签内头尾的完整空白行，保留内部段落和同一行缩进，手机里的旧正文短信也会修正显示。

## 更新楼内短信气泡

更新后，打开 **小手机 → 设置 → 内容设置 → 楼内信息注入 → 更新**，再刷新酒馆，让已有正文气泡使用新的空白行规则。手机里的显示修正加载新版即可生效。
