# 两三事 0.7.4

- 新增角色日记。主手机第二屏打开“日记”，从下拉框选择角色；查手机的角色桌面也能打开日记，并切换到只在这里可见的“废稿”。两个入口共读同一角色的成稿，缺少的角色可从“查手机 → 添加人物”补充。
- 日记按当前聊天和角色独立保存，每次点击生成追加当前模式的一篇，保留历史。生成提示要求成稿正文至少200字、废稿至少100字，以角色第一人称写生活、心绪与私密想法；打开、切换和阅读不调用模型，记录不带入普通手机生成、正文或随卡作者包。
- 成稿使用暖纸、横线、布脊、叠纸边与书签，废稿使用折角散页与划改。最新篇默认展开，旧篇以紧凑标题和日期行收起，点击即可阅读；支持长文、换行、双语及日夜主题。
- 调整楼内短信格式提示：在叙事写到短信收发时就地包完整标签，同一条新短信原话只在该处出现一次，前后继续写动作和反应。已注入的角色卡需到“设置 → 内容设置 → 楼内信息注入 → 更新”手动更新提示词。
