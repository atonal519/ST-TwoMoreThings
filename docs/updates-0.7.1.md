# 两三事 0.7.1

- 新增双方模拟语音：用户从短信＋菜单填写文字后发送，角色也可自然使用。点击语音条展开或收起原文与译文，秒数随原文长度估算；私聊、群聊、查手机及收藏都能显示。
- 修复手机消息文字中完整 Blob 编号裸露的问题，已有 `[blob.1f602]` 等目录内编号会直接显示为对应小表情。
- 查手机生成可从原文和人设线索展开朋友、工作、兴趣等私人生活话题，保留不同人物的性格与主动联系。
- 查手机消息按主楼批次折叠，当前与过去分组显示；可点“查看过去”、加载更早记录，也支持原有下拉查看方式。真实短信镜像同步采用这套显示，续写仍读取完整历史。
- 统一译文要求：新生成的非普通话文字和模拟语音（包括用汉字书写的粤语）在同次回复中逐条附普通话译文；普通话和纯符号省略译文。
- 调整新合照的人设润色：保持人物库固定外貌，以动作、距离、视线和自然神情表现性格，减少擅自添加夸张受惊表情；用户模板明确要求的造型、夸张神情及权重继续保留。已有照片保持原样。
