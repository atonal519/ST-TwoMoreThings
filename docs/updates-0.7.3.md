# 两三事 0.7.3

- 调整新增和编辑 API 弹窗，打开时先聚焦面板，输入框使用主题色内侧焦点边框。
- 新增默认收起的高级参数，可设置流式请求、温度、超时秒数、排除参数、JSON 附加参数和失败重试次数。底部保存与取消按钮固定可达，拉取模型可继续使用眼前的地址和密钥草稿。
- 流式、超时和排除参数随共享连接共用，温度、附加参数和重试次数单独用于两三事。保存只提交改动字段，空温度和空 JSON 清除对应覆盖，温度 0 可正常保存；取消保留原配置。
- 流式回答完整接收后交给原功能保存，支持分块文字和接口的 JSON 回退。默认重试次数为 0，手动设为正数后，临时连接故障、超时或限流等情况按设置追加尝试。
