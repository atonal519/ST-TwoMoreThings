# Content handwriting fonts

- **Gaegu**, supplied by `@fontsource/gaegu` 5.3.0. The Korean WOFF2 is used only for Hangul in phone message originals. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/gaegu); license and copyright: [gaegu-OFL.txt](./gaegu-OFL.txt).
- **Yomogi**, supplied by `@fontsource/yomogi` 5.3.0. The Japanese WOFF2 is used only in original text containing Hiragana or Katakana; Chinese translations, names and unclassified Han-only text retain the phone font. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/yomogi); license and copyright: [yomogi-OFL.txt](./yomogi-OFL.txt).

Both are local OFL-1.1 font assets. Registration uses `font-display: swap`, with browser loading on matching rendered content; there is no font preload, model call or language state.

The earlier Nanum Pen Script font and its OFL file remain as static compatibility assets for already loaded pages; the current phone registers Gaegu for Korean originals.
