# 两三事 · ST-TwoMoreThings

给 SillyTavern / Luker 里的角色一部小手机。

从大数字锁屏进入桌面，打开短信、论坛、两事、动态、相册、日历和设置，让手机里的日常接上当前剧情。

## 手机里有什么

- **连接预设**：设置页保留配置选择和编辑入口，下面可新增 API；名称、地址、密钥和模型在弹窗内编辑，保存生效，取消保留原配置。新增只创建共享连接，之后自行选择用途。

- **私聊与群聊**：整理联系人，也可手动配置人物、群成员、头像、网名和线上聊天习惯。联系人资料可查看“TA 给我的备注”，在正常私聊回复时顺带生成或按新依据更新，不增加请求。群聊支持成员艾特高亮、点头像插入艾特，以及引用具体消息回复。
- **日常消息**：支持双语短信、Blob 行内小表情与 Blob／Sepia 大贴纸、定位、转账，以及角色发来的图片卡。
- **相册与打孔拼贴**：自动汇总短信、群聊和帖子图片，同图保留多处来源；已生图随当前聊天保留原画面描述、来源和时间，刷新内容或删除源消息、帖子后仍可在相册查看。圆孔／燕子模板可手动拖孔位、调整取样大小，成品碎片布局固定；可下载完整作品或透明碎片 PNG。拼贴编辑草稿仅保留在当前手机会话，不改原图，不增加模型请求。
- **楼内信息注入**：在内容设置点“注入”，让主楼用简短短信格式输出、正则显示完整气泡，短信自动存入手机，也能接着聊。
- **两事微博**：手动刷新广场，一次生成约15条微博，以不同领域、人群和地方的独立公共生活为主，约5%可涉及剧情人物的公开消息，同一局部圈层至多2条，每批重新取材；配少量热评；热榜单独刷新约15个话题和摘要，打开话题后点“加载话题微博”生成约8条相关微博，重进直接阅读，话题页刷新只替换该话题；引用可读原博，详情可按需追加评论和转发，关注页按user人设与已保存公开内容独立手动刷新约15条微博，模拟可能已关注的账号，按钮仍为只读状态；标题栏可发微博，自己写或先让AI结合最近一楼正文帮写，修改后自己发布，在“我的”查看，卡片右下角菜单可编辑或删除，可填配图描述并在发布后点击生成，也支持只图；帖子、评论、回应、转发及话题内微博均可选配图，支持纯图，点击才沿现有图片设置生成。推广会穿插虚构活动与白鳥系列插件介绍；点赞会亮红心并轻微缩放，再点取消，只保存在当前手机。
- **微博回应**：本人微博下可点评论手写回复，再从右下菜单合批生成回应，或重新生成最近一批AI回应。
- **剧情论坛**：每次刷新生成约10篇帖子，每帖最多2个宽分类标签，顶部仅列本批至少2帖共用的前6类，主帖生成提示强调背景和分段展开、讨论长短混合；内容公开、作者身份匿名，可作为其他手机模块的谈资；首页显示4行正文，帖子内每次手写回帖随机使用一个网名，保存后固定，可回复楼层，输入时显示目标摘要，已发回复可点引用返回原楼，再手动加载更多自然讨论；少数配图点击才生成，首页标明有图，赞踩的虚构计数和动效只在当前界面变化。
- **ainstgram 动态**：首页一次约15条短动态，每条新生成主帖必须有配图描述，点击才生成，评论与回应只用文字和emoji；人物主页仍每次补充2–3条带图历史；留言先发布，回应继续生成，可去其他页面，回复有未读提醒。动态也能成为后续聊天的话题。刷新首页会替换上一批；刷新动态、补充个人历史及重提炼线上方式均独立拟稿，保留相应的短信、人物资料、剧情和记忆约束。
- **锁屏与桌面**：默认、「纵时」与花瓣剪纸「圆时」三种锁屏，日夜配色，支持自定义背景、未读通知和指纹按钮进入桌面。
- **字体与双语排版**：外观设置可填写字体 CSS 链接，默认使用有爱圆体，清空后使用系统字体；韩文原文使用 Gaegu，日文原文使用 Yomogi。中文译文字号更突出，原文与译文紧密排列，ainstgram 评论姓名与正文分列。
- **手机通知**：点手机上沿中央的半透明长条打开通知与日夜快切，通知历史随当前聊天保存；短信、评论回复及论坛或动态的新内容沿原保存记录，点通知打开来源或回退到对应应用后，会移除点过的这一条，保留其它通知及原消息、帖子；普通打开应用或会话不移除通知。底部“清除通知”同时清历史与当前提醒，不删消息、帖子或改已读；清后刷新也不恢复旧通知，新的通知继续出现。首次接入收录当前未读短信、群聊与动态回复。
- **聊天记录**：资料和消息随当前聊天保存，过去的记录可折叠查看；清屏只清理当前批次。
- **手机信息参考**：已保存公开帖子及折叠历史按实际知情范围进入后续手机生成，仅取近期窗口并按完整JSON预算裁切，优先自己和直接互动；当前短信段只供本会话，群回复只参考全体可能发言者共同可知的消息，公共素材仅含公开记录；明确作者可单独参考自己参与的稳定私聊、群聊，未知作者不获得这些片段，手机近期材料合计仍20条/6000字符；重生排除本平台旧稿，主内容生成统一参考最新AI一楼中的明确公开事实，仍不喂旧稿与旧账号，两事广场保持世界生活为主，不增加生成请求。开启短信带入正文后仍沿原规则，短材料不增加请求，超过3000字符才沿用一次摘要。

## 插件联动

构画提供只读月历，以及节日、生日、纪念日和自定日程；短信与群聊还可参考相关的刻度日程，这项联动需要构画提供新版日程读取接口。没有可靠剧情日期时，桌面日历显示本地日期。千千结可提供已有的相关记忆，并在人物明确对应时补充联系人头像。柏宝书开启时，可读取它已选好的剧情摘要，供短信、群聊、动态和评论参考，不增加模型调用。两个记忆插件同时开启时，手机会提示先关闭其中一个；都未开启也能正常使用。论坛和两事不读取这些记忆；两事广场采用设定和命中的相关世界书，独立热榜采用角色卡与关联世界书静态资料，在同次生成内逐一判断人物的公开身份与事件传播条件。

手机时间支持千千结、构画、myknots和柏宝书时间戳，通常取最新AI正文楼的最后结束时间；构画与同楼记忆时间可确认相差超过一小时时，优先采用记忆时间，差距较小或无法确认时保留原取法。没有可读时间时显示现实时间，不改写旧短信。

新建联系人会在本地自动生成一个固定的 Cameo 头像；有可对应的千千结头像时优先显示千千结，缺图时显示原来的 Cameo。可在现有资料页手动换图或移除，不会因重开手机重新随机。打开或重新启用手机时，也会为未人工保护的已有空头像补一次固定 Cameo；手动移除和旧资料的人工保护继续保留。

联系人资料与列表显示同一张头像；头像右侧三点菜单可上传、移除或恢复。“移除”保留空白，“恢复”重新采用千千结优先、缺图用固定 Cameo，点击保存后生效，取消不改档案。

内容设置中的默认语言可选自动、汉语、英语、粤语、日语或韩语，联系人单独填写的语言优先。汉语只显示原文，其余语言在原来的同次生成中附标准汉语译文，粤语也包含；自动按明确场景判断，没有依据时用汉语。

动态中的联系人沿用同一份头像；临时路人也会在本地生成固定 Cameo，已有未人工保护的空头像随打开手机一并补充。

图片卡可选择柏宝绘或智绘姬生成，点击后才生图。定位和转账用于剧情互动，不读取真实定位，也不处理真实资金。

主楼短信格式写入当前角色卡已绑定的主世界书，只对已注入的角色卡生效；气泡正则只用于显示，原始正文仍是简短短信块。生成结束、打开或重新启用手机时，跳过草稿和审核片段，仅同步最新AI楼正式正文里的新增短信，自动建立明确的新联系人或群聊，静默标为已读，不增加提取请求。手机已有短信只作为主楼参考，主楼来源短信不会再重复带回正文；在手机中继续聊的新消息照常参与参考。


手机模型请求沿用共享破限词设置，非空自定义保留原文，留空或只有空白时使用内置默认；修改并保存后从下一次请求生效。

文本连接在手机内置配置列表选择，共享预设提供地址和密钥，切换配置时带入目标的默认模型，重开同一配置保留已保存的自选模型。点击“编辑”可修改名称、地址、密钥和模型，留空密钥保留已保存值；拉取模型、另存和删除也在弹窗内，保存成功后生效，失败保留草稿。“新增 API”从空白表单创建共享连接，不自动选择，即使是首套连接也需自行选择。模型仍单独保存在当前两三事实例。

## 随卡使用

角色卡作者可以配好人物、群聊、头像、聊天风格与背景，再导出随卡手机。制作方法见 [作者说明](./AUTHORING.md)。

## 更新

手机设置顶部显示更新状态；首次打开会检查一次，也可点击状态按钮手动检查。显示“可更新”时，点开公告，选择“更新”或“暂不更新”。设置页导航上方的独立版本行显示版本及插件/随卡类型，“查看公告”可打开已安装版本公告；公告暂时读不到仍可更新。

插件版通过酒馆的扩展更新接口更新当前安装，完成后刷新酒馆使用。随卡版通过CDN读取同一仓库的公开发布清单，按完整提交SHA加载新核心后直接继续使用，不需要本地安装两三事扩展。检查或新核心加载失败时，当前手机仍可使用。更新不重置联系人、预设或聊天记录。

新导出的随卡脚本使用公开发布清单，不再查询 GitHub 匿名 API。已经分发的旧脚本代码不会被核心更新自动改写，需保留原脚本 ID 和数据，一次性替换代码；定制脚本还须保留自己的适配。

发布清单读取失败时，随卡手机回退至已发布的0.4.0核心，首次打开显示本次失败原因，设置里保留更新与公告入口，可手动重新检查。

发版维护：先发布核心，再同步发布清单，为清单提交创建对应的semver版本标签，刷新CDN的`@latest/release.json`别名缓存并实际回读版本与SHA后宣布更新；`cache: no-store`或添加查询参数不能代替别名缓存刷新。

插件和随卡入口共用随包提供的 `dist/runtime.js` 核心，减少启动时逐个加载源码模块的请求；样式和素材保留原路径。

开发时在修改源码后运行 `npm run build`，再运行 `npm test` 和相关浏览器检查。构建使用固定的 Vite 8.2.2，提交源码时一并更新生成的 `dist/runtime.js`。

手机标题、时钟和操作标签不再拖选，输入与消息正文仍可选字复制；桌面图标统一采用当前主题强调色，经典锁屏图案铺至屏幕底部。

会话、微博、通讯录和头像操作在触发按钮旁展开小菜单，设置字段使用内部下拉。单条短信点击气泡后在侧边浮起删除操作，当前群消息另有引用；图片卡通过旁边的三点进入同一操作。展开“查看过去”后，每段日期／主楼标签旁的删除图标可确认删除整段历史，保留其他段和当前草稿；楼号与宿主正文从0起的编号一致。联系人和群聊删除使用手机内确认，连接设置首次默认折叠。异步刷新保留正在编辑的输入、选区和中文输入状态，微博与动态的发布时间显示为可读日期和时分。

当前版本：**0.5.0**。本版变化见 [更新公告](./docs/updates-0.5.0.md)，插件联动说明见 [INTEGRATIONS.md](./INTEGRATIONS.md)。

模型答复优先按标准JSON读取，完整答复中的引号、逗号等格式错误可在本地兼容，不增加模型请求；仍按原内容与身份规则保存。使用固定版 [jsonrepair](./src/vendor/jsonrepair/README.md)，ISC许可随源码与运行包保留。

两事“我的”顶部显示当前个人资料头像与网名、模拟关注/粉丝/转评赞数，下方保留本人微博列表与原编辑删除入口。

本人微博下可逐条写回复，再从右下角菜单一次生成回应；“重新生成”只替换最近一批AI回应，保留本人回复和其他评论。

联系人资料可手工指定所属人物，同人的账号共享已折叠的近期记忆，名字、头像和线上表达各自保留，归属不向他人公开；本人账号不会由AI代发。本人微博互动按当前唯一账号和内容默认给少量自然评论，转发可为0，仅资料明确当前号无人关注时可全空，人设提及的其他账号不自动替代当前昵称。

模型生成的自然正文及译文共用句末收尾，保留既有标点和表情结尾，手写、标题与图片描述原样。
