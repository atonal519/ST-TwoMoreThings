# 两三事 · ST-TwoMoreThings

给 SillyTavern / Luker 里的角色一部小手机。

从大数字锁屏进入桌面，打开短信、论坛、动态、日历、待办和设置，让手机里的日常接上当前剧情。

## 手机里有什么

- **私聊与群聊**：整理联系人，也可手动配置人物、群成员、头像、网名和线上聊天习惯。群聊支持成员艾特高亮、点头像插入艾特，以及引用具体消息回复。
- **日常消息**：支持双语短信、Blob 行内小表情与 Blob／Sepia 大贴纸、定位、转账，以及角色发来的图片卡。
- **剧情论坛**：刷新查看当前故事中的帖子与讨论。
- **ainstgram 动态**：手动刷新好友和路人的近况，人物主页可补充历史；留言先发布，回应继续生成，可去其他页面，回复有未读提醒。动态也能成为短信话题或让角色主动联系。刷新首页会替换上一批。
- **锁屏与桌面**：默认、「纵时」与花瓣剪纸「圆时」三种锁屏，日夜配色，支持自定义背景、未读通知和指纹按钮进入桌面。
- **手机内推送**：离开对应页面后，短信、评论回复以及论坛或动态生成完成会在手机顶部提醒，点按回到对应内容；短信与评论回复的未读同时保留在锁屏。
- **聊天记录**：资料和消息随当前聊天保存，过去的记录可折叠查看；清屏只清理当前批次。
- **轻量待办**：短信中的明确约定可生成建议卡，确认后加入待办；记录剧情开始、结束时间和相关人，未完成项显示桌面角标。完成需手动勾选，剧情进展不会自动同步。
- **手机信息参考**：私聊保留近期记录，群聊可按成员知情范围参考私聊约定，动态也可成为话题。开启短信带入正文后，当前短信与已确认待办作为参考，由主楼本次生成结合已有剧情决定如何采用；短材料不增加请求，超过3000字符才沿用一次摘要，同时核对进展，不另加分析调用。

## 插件联动

构画提供只读月历、节日和纪念日；千千结可提供已有的相关记忆，并在人物明确对应时补充联系人头像。没有这些插件也能使用短信与论坛。

图片卡可选择柏宝绘或智绘姬生成，点击后才生图。定位和转账用于剧情互动，不读取真实定位，也不处理真实资金。

## 随卡使用

角色卡作者可以配好人物、群聊、头像、聊天风格与背景，再导出随卡手机。制作方法见 [作者说明](./AUTHORING.md)。

## 更新

手机设置顶部显示更新状态；首次打开会检查一次，也可点击状态按钮手动检查。显示“可更新”时，点开公告，选择“更新”或“暂不更新”。“内容设置”中可查看已安装版本公告；公告暂时读不到仍可更新。

插件版通过酒馆的扩展更新接口更新当前安装，完成后刷新酒馆使用。随卡版读取同一仓库的公开发布清单，加载新核心后直接继续使用，不需要本地安装两三事扩展。检查或新核心加载失败时，当前手机仍可使用。更新不改联系人、预设或聊天内容。

新导出的随卡脚本使用公开发布清单，不再查询 GitHub 匿名 API。已经分发的旧脚本代码不会被核心更新自动改写，需保留原脚本 ID 和数据，一次性替换代码；定制脚本还须保留自己的适配。

当前版本：**0.3.7**。插件联动说明见 [INTEGRATIONS.md](./INTEGRATIONS.md)。
