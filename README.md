# 两三事（ST-TwoMoreThings）· 0.1.0

酒馆前端扩展，包含独立手机锁屏、短信、只读论坛与设置。日间「回声」使用米白、矿蓝与青铜线环；夜间「深蓝」按已选原稿使用深海蓝、象牙白大数字、朱红方形冒号及独立的银白/蓝色折叠线带，时间纵向延伸并被前景穿插遮挡。两套桌面有各自的搭配与构图；素材、SVG及Dorsa时钟字体随插件本地加载。关闭与页面标题/操作在同一行正常布局；桌面关闭仍在角落。设置放在底部导航，主题放在设置内。短信与论坛铺开到窗口边缘，聊天复用用户授权的溯之气泡与输入区布局，论坛保持统一的内容层级和间距。

内容生成使用已有相关记忆、最新一个AI楼和激活世界书；当前批次中自己参与的聊天在主楼生成前摘要到100字以内。历史折叠保留，清屏只清当前批，旁观群不回流。

## 安装与查看

在酒馆的「扩展 → 安装扩展」中填写：

```text
https://github.com/atonal519/ST-TwoMoreThings
```

安装后刷新页面，在魔法棒菜单找到「两三事」，不需要重启酒馆。默认安装目录为 `public/scripts/extensions/third-party/ST-TwoMoreThings`；已有的 `ST-PocketPhone` 目录也可继续使用，两者使用相同存档字段，请保留一份安装。

窗口沿用千千结默认尺寸：电脑端宽360px、默认高600px并按视口限制，靠右显示；手机端在640px以下左右留10px，上下留20px并计入安全区。主窗使用Shadow DOM、独立命名空间及继承样式重置；输入区的编辑键不会触发酒馆快捷键，窗口外的酒馆仍可操作。

只想查看界面和流程，可在当前酒馆地址后加 `/scripts/extensions/third-party/ST-TwoMoreThings/tests/preview.html`（旧目录安装请将路径中的目录名换成 `ST-PocketPhone`）。这个页面使用同一份生产入口、存储和业务模块，宿主与模型返回是明确标注的示例；不会向真实模型发送请求，不修改真实聊天或 API 设置。

## 入口与设置

显示名为“两三事”，项目名为 `ST-TwoMoreThings`，当前版本为 `0.1.0`。已有 `pocketPhone` 存档和连接不迁移、不重置。

魔法棒和悬浮球使用用户提供的手机 SVG；刷新与设置图标同样使用用户提供的新 SVG。悬浮球沿用千千结的36px圆形、拖动、桌面位置保存、移动端临时位置及请求中呼吸灯行为，使用本插件独立位置键和日夜配色；默认与千千结错开一个球的位置。悬浮球默认开启，QR默认关闭。

设置最上方是“启用两三事”总开关，按当前角色卡保存，其他卡不受影响。关闭后手机业务和正文回流不生效，入口和档案保留，仍可进入设置。关闭时已发出的请求不再写入手机业务结果；不承诺中止柏宝绘或宿主已经接收的请求。

设置分为“连接设置”“外观设置”“内容设置”三个折叠抽屉；删除固定解释段落。连接默认展开，外观和内容默认收起，折叠状态在本次界面内保留。我的资料入口仍在抽屉上方。外观内设置主题、悬浮球、QR和主页背景；内容目前只有短信带入正文。

自行填写连接时可点击“拉取模型”，使用填写的地址和密钥读取模型列表；无须先填模型，也不自动保存连接。列表采用千千结的内嵌展开和本地搜索逻辑，点击或键盘选择模型，保留手动填写；不用浏览器弹窗。搜索不重复请求接口，修改地址/密钥后清除旧列表。

背景图片先在浏览器压缩为最长1600px的WebP，再通过宿主已有 `/api/images/upload` 保存到酒馆用户图片目录 `data/<用户>/user/images/pocket-phone/`；聊天元数据仅保存日/夜各自的图片路径。用户头像仍按原约定压缩后存入当前聊天。自定义背景以cover铺在数字下方，恢复默认回到原日夜前景构图；恢复默认不删除服务器图片。单独导出聊天不包含图片文件，完整迁移需同时带走用户图片目录。

悬浮球和QR显示偏好保存在本插件全局设置；主题、背景及内容仍随当前聊天。QR通过酒馆Quick Replies API创建“两三事”组的手动按钮，命令为 `/tmt-open`；不打开Quick Replies总开关、不设置自动执行，不发送正文。关闭QR只移除自己的按钮，不删除用户添加的其他按钮。

## 表情、消息卡与锁屏

聊天输入区左侧的加号在输入栏下方展开表情、定位和转账；展开时输入栏上移，菜单采用紧凑的小图标网格。内置 Blob Emoji 24张和 Sepia 6张，原图随插件加载，选择即发送；角色也可从同一份有语义标签的目录发表情。选择面板标注作者，完整许可见 `assets/stickers/`。

定位是剧情内地点卡，不读取真实定位、不请求地图服务。转账是剧情消息，支持金额、币种、备注，群聊明确选择收款人。当前批次的收款人可收下或退回；角色也可回复处理用户发出的转账。结果更新原记录，进入下一次手机上下文与正文摘要，不增加伪造的用户短信。过去批次只读，不再收款或退回。

角色发来图片卡后，点击才生成。手机用自己的生成连接把照片描述整理为画面提示；外貌和衣着从柏宝绘公开人物库的完整标签读取，辨明发图者与照片中的人物。没有对应人物档案或外貌标签时提示先在柏宝绘补档，不自行编外貌。衣着以人物库当前记录为准。支持独立角色提示的后端分别传入；ComfyUI/旧模型将相同标签合入整体提示。只支持柏宝绘的公开生图接口，沿用它的后端与图库，不另配生图渠道或读取密钥。

生成后更新同一条手机消息，仅保存图库路径和种子，重开只查看，不重复生图。正文上下文只收到图片描述，不包含绘图标签、文件路径或base64。图片同时保留在柏宝绘图库；删手机消息会移除手机记录与上下文，图库原图保留。未生成的过去图片只能查看描述，不能从只读历史触发生图。图片生成不增加正文楼层。

私聊与群聊收到未读回复后，锁屏按会话显示通知卡，点击进入对应聊天；已读后消失。正在看的会话直接保存为已读，避免为每次回复再多保存一次。旧档案没有未读字段的消息按已读处理，不把全部旧短信变成新通知；已读标志与消息一起保存、删除和清屏，不维护另一套消息档案。

锁屏天气在日期上方。当前未安装提供接口的构画版本时使用固定的装饰天气，不请求真实天气，也不把装饰天气发送给模型。构画只读接口约定见 [INTEGRATIONS.md](./INTEGRATIONS.md)；完整日历页面仍待后续接入。

## 使用

- 底部图标打开短信、论坛、设置；内页另有锁屏入口。设置内切换日间/夜间，选择保存在当前聊天。
- 加号内「整理通讯录」一次模型请求同时查找新增联系人和有必要的群聊，读取已有通讯录、千千结简要人物资料（如可用）、角色卡、关联世界书目录和最新剧情。只补充，不重置已有资料、群名与聊天。新增人物推演具体线上聊天方式，性格依据不在界面展示；已有联系人需单独更新线上方式时，在资料页提炼，不借整理通讯录覆盖。旧版edited记录无法还原改动字段，保留原资料；可在联系人资料点击“重新提炼线上方式”，生成后先填入编辑框，检查后点保存才落盘。
- 短信页的加号统一打开整理通讯录、添加联系人和创建群聊；聊天标题或右上菜单编辑已有联系人：姓名、网名、头像、线上聊天方式和语言习惯。设置内「我的资料」默认读取酒馆当前user名字，编辑自己的姓名、网名、头像，不设置用户的说话方式，也不改酒馆人设。资料随当前聊天保存，不全局共享，也不跨同卡的其他聊天共享。网名用于手机显示，姓名用于模型归属。头像可填地址或选本地图片，本地图片缩至最长384px后随当前聊天保存；头像图片不送给模型。
- 「发送」仅保存自己的短信，允许连发。「继续」才生成对方回复，没有新短信时也可使用。输入框的草稿不送给模型。
- 表单字段、保存按钮、成员行与页面留白采用统一紧凑尺寸；发送/继续为小图标，输入框无占位文字且支持多行自适应。char头像对齐连续发言第一条，user对齐末条；群聊首条气泡上方显示小号姓名，连续发言不重复。空短信页及未聊天的联系人不再显示“还没有短信”。
- 个人、联系人和群聊使用同一套居中头像编辑，可填地址、上传本地图片或移除；群头像同时显示在通讯录和群聊标题。资料页按钮只写“保存”“删除”，分别使用主题色和红色实底。
- 聊天菜单或资料页可删除联系人/群聊，先二次确认。删联系人会清掉手机资料、全部私聊、历史和草稿，移出各群并删除其群内发言，保留群及其他人的记录；删群则清该群资料、全部群消息和历史。不删除角色卡、世界书或千千结源资料，不设阻止再次提取的标记。重新整理可添加回来，旧短信不会恢复。
- 回复前检查当前剧情时间/场景、联系人的活动与动机、语言环境和线上习惯，只返回实际短信，不显示分析。双语环境用英文原文与对应中文译文，译文在气泡内分隔显示；短句、分条及仅符号的回复均可。
- 点气泡后，点击气泡朝页面中央一侧的小垃圾桶（char右侧、user左侧，均与气泡居中）可永久删除该条短信；聊天右上菜单清空当前主楼时间点之后的短信及草稿，保留过去的记录。删除直接更新存档、后续短信上下文及正文参考，无隐藏历史或回收站；不清其他联系人，不回溯改写已生成正文。
- 更多/加号菜单及单条操作在点击手机内外其他位置时收起；输入节点保留，可直接开始打字。
- 群聊支持手动选成员创建和编辑，也随「整理通讯录」一起识别，可包含本次新增联系人。缺少可确定成员、没有依据或没有创建必要时不创建；同成员构成不重复、不覆盖已有群名。资料整理读取关联世界书的非禁用目录，和续写时的关键词激活分开。
- 群内「发送」只保存，「继续」一次请求带入所有成员的性格、线上习惯与语言资料，并使用最新一个AI楼、剧情时间、当前批次全部群消息和按规则激活的世界书；千千结来源成员的相关资料通过一次公开桥接读取。模型先返回成员及本轮发言者的身份锚定，再生成带发言者id的消息。成员可沉默、互相回应或全员不发言；不代写用户。原文、翻译、身份、剧情时间及实际保存时间作为同一条消息保存，支持删除和清空。
- 建群时不选自己即为旁观模式：可以点继续查看成员互动，没有发送输入框。自己参与的群聊可随参考开关一起摘要回流；旁观群不自动回流。群消息不会混入另一段私聊上下文。
- 论坛只浏览，点击「刷新」生成一批完整帖子与回帖并替换旧批次。打开帖子不调用模型。
- 「短信带入正文」默认关闭，开启后在下一次正文生成中将当前批次、自己参与的聊天压成100字以内摘要作参考，不创建楼层，不向已有楼层追加内容。

正文生成前会等待一次手机模型摘要：覆盖当前批次中你参与的全部私聊和群聊，不按40条截断；一句问答也摘要。摘要总共100字以内，保留人物、问答结果、约定与重要未决事项，不另造待办状态，不把答应说成已经履行。发送、编辑、删除、开关只清除已放入的参考，不额外调用摘要模型。关闭回流、没有当前消息、模拟生成或静默生成均不摘要。摘要失败会说明本次正文未带入手机消息，不退回注入原文。

每条新消息保存所属AI楼与该楼结束时间构成的卡口，同一楼内的消息归同一批，连续两楼即使时间相同也能区分。最新一批正常收发；过去的批次在聊天区显示“查看过去”，展开按卡口查看，只读但可永久删除单条，输入区始终发送到当前批。过去记录按60条逐步展开。旧版消息缺少所属楼，保留为“早期记录”，不伪造楼层归属。

手机生成使用最新一个AI楼的完整正文、当前批次会话和联系人资料；相关记忆通过千千结公开readContext接口读取，私聊最多约4000字，群聊一次读取全体相关成员最多约6000字。不使用作者侧routerText充当人物知情。未安装千千结或记忆未就绪时不补猜旧事。世界书在私聊、群聊和论坛生成时实际读取：蓝灯常驻；绿灯以最新AI正文、当前聊天和相关人物为扫描文本，支持主关键词、四种次关键词逻辑、正则、大小写、整词及user/char宏。读取卡、聊天、人设与全局关联的世界书，跳过禁用条目；总读取预算约24000字。当前实现基础只读激活，不等同于完整宿主世界书引擎，未移植递归、概率、分组互斥和时效规则，也不改宿主的激活状态或作者注记。整理通讯录属于资料整理，可读取关联世界书的非禁用目录。

主页与新短信优先读取最新 AI 正文楼中的千千结/构画时间戳（`QQJ`、`SDC`，兼容 `myknots`），取结束时间，没有结束戳时取开始时间。剧情日期与星期按原文显示，不换算虚构纪年；剧情时间只随主楼更新，不按现实分钟推进。当前楼没有可读时间时回退现实时间，主页此时按分钟刷新。短信时间在发送或请求回复时确定，显示在正常排版中；已有短信保持原记录，不推测补写历史时间。

## 连接与保存

手机连接与正文生成分开。默认跟随千千结当前连接，其次是构画当前连接；也可选共享预设。地址、密钥和模型每次从原配置读取，修改后下次请求自动使用新值。明确选中的来源不可用时需要重新选择或补全，不自动换到另一条连接。

请求在发出时使用当前的`fetch`调用链，使稍后安装的「最近请求记录」也能正常捕获。魔法棒入口使用宿主菜单条目和图标栏，支持点击、Enter和空格。

没有现成连接时可自行填写 OpenAI 兼容的地址、密钥、模型，保存到千千结与构画共用的预设池，不改它们的当前选择。手机全局设置只保存自己的来源引用。手机请求使用普通非流式回复，读取所选连接的超时设置和适用的参数排除设置。

联系人、自己的手机资料、私聊与群聊消息、群资料、主题、当前论坛和注入开关保存在当前聊天元数据的 `pocketPhone` 字段。保存只更新自己的字段，不改写正文消息。每条短信保留实际保存时间 `createdAt`（ISO年月日时分秒及毫秒）、可见时分和可读的剧情日期/星期，双语时另存译文。没有自动到期、自动截断历史；聊天存档保留且保存成功时，记录可持续保留。界面当前默认显示60条，历史也分次展开；这不是存储上限。当前批次的模型上下文不按40条截断，过去批次不会重复喂给当前回复和主楼摘要。

打开、浏览、手动编辑资料或创建群聊、「发送」、删除和切换主题不调用模型。「继续」、「整理通讯录」、论坛「刷新」、资料内“重新提炼线上方式”和未生成的图片卡会向选中的接口发起请求；图片卡还会调用柏宝绘生图；开启短信回流后，正常生成主楼前另有一次摘要请求。首版不包括自动候选联系人、正文楼内气泡、论坛发帖与回帖。

## 验证范围

本地 Node 测试覆盖原生酒馆与 Luker 的保存接口形状、保留外部字段、共享预设读取与保存、正式回答解析、短信两按钮、主动回复、千千结简要资料复用、上下文读取范围、论坛换新、剧情时间提取与新短信时间。浏览器测试从真实 `initialize()` 入口执行上述页面操作、草稿保留、联系人信息、正文参考开关、关闭再打开及 390px 布局。模型转发、宿主存档和事件使用受控接口；没有调用真实模型，也没有写入真实用户存档或设置。

原生酒馆与 Luker 的上下文、保存和生成入口已对照源代码；尚未完成两套真实宿主的持久化、真实模型返回、实际手机设备及软键盘验证。原生酒馆 `saveMetadata()` 自身不提供完整的持久化成功反馈，本插件不宣称已独立确认磁盘保存。

运行离线测试：

```sh
npm test
```

浏览器检查使用 `node tests/browser.mjs`，需要现有 Playwright 与 Chromium。可通过 `POCKET_PLAYWRIGHT_MODULE` 指向可解析 Playwright 的 package.json，`POCKET_BROWSER_EXECUTABLE` 指定浏览器，`POCKET_PREVIEW_URL` 指定示例页面，`POCKET_SCREENSHOTS` 指定截图目录；不在插件安装时下载依赖。测试未运行不等于通过。

`node tests/host-ui.browser.mjs` 从manifest加载正式入口，检查原生酒馆/Luker两种模拟宿主的自动注册、窗口几何、宿主样式与键盘隔离。模拟页面不会访问真实聊天或调用真实模型。

## 随卡适配

在手机里配好人物、群聊、头像、线上方式、语言与日夜背景后，从“设置 → 内容设置 → 导出随卡包”生成酒馆助手角色脚本JSON。作者配置随卡保存；读者仍需酒馆助手，手机核心通过随卡加载脚本获取。制作和测试步骤见[AUTHORING.md](./AUTHORING.md)。

本机图片随包内嵌，短信、论坛运行记录和API凭证不导出。已有手机档案优先保留，不因更新核心重置；独立版和卡内版共用当前聊天档案，开关和入口偏好分开。独立版每次打开带卡内手机的角色卡仍提醒，不自动隐藏、接管或协调双开。

0.1.0已包含随卡入口。分发时选择“跟随正式更新”，以后核心更新并在CDN生效后，读者刷新酒馆页面即可获取；“本机测试”仅用于当前酒馆调试。

素材：日间回声前景为本项目单独生成的素材；夜间折带前景由本项目已确认的夜间原稿去除文字、图标和背景后整理为透明素材。两者均不复用第三方参考项目图片。应用 SVG 由用户提供。时钟字体使用 [Dorsa](https://github.com/google/fonts/tree/main/ofl/dorsa)，原字体文件随包提供，授权见 `assets/clock-font-license.txt`，中文使用设备已有字体。聊天布局来自用户授权复用的本地溯之项目；配色由小手机主题提供。

联系人、短信、群聊、论坛与摘要提示词根据本插件已确认的需求独立编写，没有搬入第三方参考项目的提示词，在 [`src/prompts.js`](src/prompts.js) 与群聊独立模块 [`src/groups.js`](src/groups.js) 中供审阅。

当前版本为 `0.1.0`，验证范围与尚未实现的功能见上文。
