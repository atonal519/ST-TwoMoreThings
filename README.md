# 两三事 · ST-TwoMoreThings

给 SillyTavern / Luker 里的角色一部小手机。

从大数字锁屏进入桌面，打开短信、论坛、动态、日历和设置，让手机里的日常接上当前剧情。

## 手机里有什么

- **私聊与群聊**：整理联系人，也可手动配置人物、群成员、头像、网名和线上聊天习惯。
- **日常消息**：支持双语短信、Blob Emoji 与 Sepia 表情、定位、转账，以及角色发来的图片卡。
- **剧情论坛**：刷新查看当前故事中的帖子与讨论。
- **ainstgram 动态**：手动刷新好友和路人的近况，人物主页可补充历史；刷新首页会替换上一批，虚拟点赞、转发和短评论只供浏览。
- **锁屏与桌面**：默认、「纵时」与花瓣剪纸「圆时」三种锁屏，日夜配色，支持自定义背景、未读通知和指纹按钮进入桌面。
- **聊天记录**：资料和消息随当前聊天保存，过去的记录可折叠查看；清屏只清理当前批次。
- **短信带入正文**：可将当前发生的手机聊天压成简短摘要，让正文知道手机里发生了什么。

## 插件联动

构画提供只读月历、节日和纪念日；千千结可提供已有的相关记忆。没有这些插件也能使用短信与论坛。

图片卡可选择柏宝绘或智绘姬生成，点击后才生图。定位和转账用于剧情互动，不读取真实定位，也不处理真实资金。

## 随卡使用

角色卡作者可以配好人物、群聊、头像、聊天风格与背景，再导出随卡手机。制作方法见 [作者说明](./AUTHORING.md)。

当前版本：**0.3.1**。插件联动说明见 [INTEGRATIONS.md](./INTEGRATIONS.md)。
