# 两三事 · ST-TwoMoreThings

给 SillyTavern / Luker 里的角色一部小手机。

从大数字锁屏进入桌面，打开短信、论坛、两事、动态、日历和设置，让手机里的日常接上当前剧情。

## 手机里有什么

- **私聊与群聊**：整理联系人，也可手动配置人物、群成员、头像、网名和线上聊天习惯。群聊支持成员艾特高亮、点头像插入艾特，以及引用具体消息回复。
- **日常消息**：支持双语短信、Blob 行内小表情与 Blob／Sepia 大贴纸、定位、转账，以及角色发来的图片卡。
- **楼内信息注入**：在内容设置点“注入”，让主楼用简短短信格式输出、正则显示完整气泡，短信自动存入手机，也能接着聊。
- **两事微博**：手动刷新广场，一次生成约15条微博，以不同领域、人群和地方的独立公共生活为主，约5%可涉及剧情人物的公开消息，同一局部圈层至多2条，每批重新取材；配少量热评；热榜单独刷新约15个话题和摘要，打开话题后点“加载话题微博”生成约8条相关微博，重进直接阅读，话题页刷新只替换该话题；引用可读原博，详情可按需追加评论和转发，关注页按user人设与已保存公开内容独立手动刷新约15条微博，模拟可能已关注的账号，按钮仍为只读状态；标题栏可发微博，自己写或先让AI结合最近一楼正文帮写，修改后自己发布，在“我的”查看，卡片右下角菜单可编辑或删除，可填配图描述并在发布后点击生成，也支持只图；少量配图点开才生成。推广会穿插虚构活动与白鳥系列插件介绍；点赞会亮红心并轻微缩放，再点取消，只保存在当前手机。
- **剧情论坛**：刷新查看当前故事中的帖子与讨论。
- **ainstgram 动态**：手动刷新好友和路人的近况，人物主页可补充历史；留言先发布，回应继续生成，可去其他页面，回复有未读提醒。动态也能成为短信话题或让角色主动联系。刷新首页会替换上一批；刷新动态、补充个人历史及重提炼线上方式均独立拟稿，保留相应的短信、人物资料、剧情和记忆约束。
- **锁屏与桌面**：默认、「纵时」与花瓣剪纸「圆时」三种锁屏，日夜配色，支持自定义背景、未读通知和指纹按钮进入桌面。
- **手机内推送**：离开对应页面后，短信、评论回复以及论坛或动态生成完成会在手机顶部提醒，点按回到对应内容；短信与评论回复的未读同时保留在锁屏。
- **聊天记录**：资料和消息随当前聊天保存，过去的记录可折叠查看；清屏只清理当前批次。
- **手机信息参考**：已保存公开帖子及折叠历史按实际知情范围进入后续手机生成，仅取近期窗口并按完整JSON预算裁切，优先自己和直接互动；当前短信段只供本会话，群回复只参考全体可能发言者共同可知的消息，公开批量内容不带私聊；重生排除本平台旧稿，主内容生成统一参考最新AI一楼中的明确公开事实，仍不喂旧稿与旧账号，两事广场保持世界生活为主，不增加生成请求。开启短信带入正文后仍沿原规则，短材料不增加请求，超过3000字符才沿用一次摘要。

## 插件联动

构画提供只读月历、节日和纪念日；千千结可提供已有的相关记忆，并在人物明确对应时补充联系人头像。柏宝书开启时，可读取它已选好的剧情摘要，供短信、群聊、动态和评论参考，不增加模型调用。两个记忆插件同时开启时，手机会提示先关闭其中一个；都未开启也能正常使用。论坛和两事不读取这些记忆；两事广场采用设定和命中的相关世界书，独立热榜采用角色卡与关联世界书静态资料，在同次生成内逐一判断人物的公开身份与事件传播条件。

手机时间支持千千结、构画、myknots和柏宝书时间戳，通常取最新AI正文楼的最后结束时间；构画与同楼记忆时间可确认相差超过一小时时，优先采用记忆时间，差距较小或无法确认时保留原取法。没有可读时间时显示现实时间，不改写旧短信。

新建联系人会在本地自动生成一个固定的 Cameo 头像；有可对应的千千结头像时优先显示千千结，缺图时显示原来的 Cameo。可在现有资料页手动换图或移除，不会因重开手机重新随机。打开或重新启用手机时，也会为未人工保护的已有空头像补一次固定 Cameo；手动移除和旧资料的人工保护继续保留。

联系人资料与列表显示同一张头像；头像右侧三点菜单可上传、移除或恢复。“移除”保留空白，“恢复”重新采用千千结优先、缺图用固定 Cameo，点击保存后生效，取消不改档案。

内容设置中的默认语言可选自动、汉语、英语、粤语、日语或韩语，联系人单独填写的语言优先。汉语只显示原文，其余语言在原来的同次生成中附标准汉语译文，粤语也包含；自动按明确场景判断，没有依据时用汉语。

动态中的联系人沿用同一份头像；临时路人也会在本地生成固定 Cameo，已有未人工保护的空头像随打开手机一并补充。

图片卡可选择柏宝绘或智绘姬生成，点击后才生图。定位和转账用于剧情互动，不读取真实定位，也不处理真实资金。

主楼短信格式写入当前角色卡已绑定的主世界书，只对已注入的角色卡生效；气泡正则只用于显示，原始正文仍是简短短信块。生成结束、打开或重新启用手机时，同步最新AI楼里的新增短信，自动建立明确的新联系人或群聊，静默标为已读，不增加提取请求。手机已有短信只作为主楼参考，主楼来源短信不会再重复带回正文；在手机中继续聊的新消息照常参与参考。


手机模型请求沿用共享破限词设置，非空自定义保留原文，留空或只有空白时使用内置默认；修改并保存后从下一次请求生效。

文本连接在手机内置配置列表选择，共享预设提供地址和密钥，切换配置时带入目标的默认模型，重开同一配置保留已保存的自选模型；可以拉取模型列表另选，点击保存后用于后续生成，自行填写连接会创建共享预设；现有连接可编辑地址和密钥、命名另存或确认删除，列表直接显示配置名，模型仍单独保存在两三事。

## 随卡使用

角色卡作者可以配好人物、群聊、头像、聊天风格与背景，再导出随卡手机。制作方法见 [作者说明](./AUTHORING.md)。

## 更新

手机设置顶部显示更新状态；首次打开会检查一次，也可点击状态按钮手动检查。显示“可更新”时，点开公告，选择“更新”或“暂不更新”。设置页导航上方的独立版本行显示版本及插件/随卡类型，“查看公告”可打开已安装版本公告；公告暂时读不到仍可更新。

插件版通过酒馆的扩展更新接口更新当前安装，完成后刷新酒馆使用。随卡版通过CDN读取同一仓库的公开发布清单，按完整提交SHA加载新核心后直接继续使用，不需要本地安装两三事扩展。检查或新核心加载失败时，当前手机仍可使用。更新不重置联系人、预设或聊天记录。

新导出的随卡脚本使用公开发布清单，不再查询 GitHub 匿名 API。已经分发的旧脚本代码不会被核心更新自动改写，需保留原脚本 ID 和数据，一次性替换代码；定制脚本还须保留自己的适配。

发版维护：先发布核心，再同步发布清单，为清单提交创建对应的semver版本标签，刷新CDN的`@latest/release.json`别名缓存并实际回读版本与SHA后宣布更新；`cache: no-store`或添加查询参数不能代替别名缓存刷新。

插件和随卡入口共用随包提供的 `dist/runtime.js` 核心，减少启动时逐个加载源码模块的请求；样式和素材保留原路径。

开发时在修改源码后运行 `npm run build`，再运行 `npm test` 和相关浏览器检查。构建使用固定的 Vite 8.2.2，提交源码时一并更新生成的 `dist/runtime.js`。

手机标题、时钟和操作标签不再拖选，输入与消息正文仍可选字复制；桌面图标统一采用当前主题强调色，经典锁屏图案铺至屏幕底部。

当前版本：**0.4.0**。插件联动说明见 [INTEGRATIONS.md](./INTEGRATIONS.md)。
